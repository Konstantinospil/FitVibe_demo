## User Story

**As a** authenticated user  
**I want** to record and update my biometric and performance measurement values  
**So that** I can track my progress consistently over time

## Acceptance Intent

- users can record values for enabled definitions;
- values are validated against canonical definition constraints;
- unit conversion does not alter the semantic value;
- historical records retain timestamps and definition identity.

Canonical AC files will be created or marked verified only after the live implementation is compared with this contradiction-free target documentation. This story is therefore product scope, not automatically a future implementation issue.
