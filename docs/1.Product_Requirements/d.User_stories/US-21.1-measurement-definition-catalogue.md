## User Story

**As a** system administrator  
**I want** to manage a canonical catalogue of biometric and performance measurement definitions  
**So that** users can record comparable measurements with consistent metadata

## Acceptance Intent

- definitions have stable identifiers and normalized uniqueness;
- each definition identifies category, unit type, display unit/granularity, and validation range;
- metric/imperial metadata is represented without creating semantically duplicate definitions;
- historical references remain valid when display metadata changes.

Canonical AC files will be created or marked verified only after the live implementation is compared with this contradiction-free target documentation. This story is therefore product scope, not automatically a future implementation issue.
