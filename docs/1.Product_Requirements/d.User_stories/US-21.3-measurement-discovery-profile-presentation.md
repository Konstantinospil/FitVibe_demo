## User Story

**As a** authenticated user  
**I want** to search available measurements and choose which ones are shown on my profile  
**So that** my profile reflects the measurements relevant to me

## Acceptance Intent

- users can search canonical measurement definitions;
- results expose definition metadata sufficient to identify the measurement;
- users can add/remove measurements from their profile presentation;
- choices persist and remain accessible via keyboard and assistive technology.

Canonical AC files will be created or marked verified only after the live implementation is compared with this contradiction-free target documentation. This story is therefore product scope, not automatically a future implementation issue.
