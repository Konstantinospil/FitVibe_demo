# Implementation working notes

`docs/6.Implementation/` holds **local** planning, review, and verification drafts. Those files are **gitignored** so they do not compete with the product SSOT under `docs/1.Product_Requirements/` and `docs/2.Technical_Design_Document/`.

## What to use instead

| Kind | Canonical location |
| --- | --- |
| Epics, activities, stories, ACs | `docs/1.Product_Requirements/` |
| Database encryption plans / verification | [`E20-IMPLEMENTATION-PLANS.md`](../1.Product_Requirements/b.Epics/E20-IMPLEMENTATION-PLANS.md), [`E20-VERIFICATION-REPORT.md`](../1.Product_Requirements/b.Epics/E20-VERIFICATION-REPORT.md) |
| Architecture decisions | `docs/2.Technical_Design_Document/2.f.Architectural_Decision_Documentation/` |
| QA / RTM | `docs/4.Testing_and_Quality_Assurance_Plan/` and `docs/1.Product_Requirements/e.Acceptance_Criteria/` |

If you keep private notes here, they stay on your machine. Do not link epics at shipped documentation to files in this folder.
