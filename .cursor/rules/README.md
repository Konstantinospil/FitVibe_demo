# FitVibe project rules

Cursor loads only `.mdc` files here. Keep them short. Do not `@`-include large source files.

| File           | When                          |
| -------------- | ----------------------------- |
| `core.mdc`     | Every chat                    |
| `backend.mdc`  | `apps/backend/**/*.ts`        |
| `frontend.mdc` | Frontend source and i18n JSON |
| `testing.mdc`  | `tests/` and `*.test.*`       |
